## ✨ Platform Features Covered

- **Structured Learning Paths** — 5-level content hierarchy from zero to certified
- **Browser-Based Lab Terminal** — Live terminal environments, zero VM setup
- **Exam-Blueprint Assessments** — Competency-weighted scoring, gamification & certificates
- **Spaced-Repetition Flashcards** — SM-2 algorithm for smarter review
- **Progress & Analytics** — Domain-level readiness scores and streaks
- **Visual Study Books** — CertKraft Press illustrated certification guides
- **KIRA** — AI Learning Companion for gap analysis and adaptive study
- **India-Native Billing** — Razorpay, PhonePe, Stripe + GST-compliant invoicing

## 🔄 How to Update

### Edit content
1. Download `index.html` from this repo
2. Open in any text editor (VS Code recommended)
3. Find the slide you want to edit — each is marked with a comment e.g. `<!-- SLIDE 3: LEARNING PATHS -->`
4. Make your changes
5. Re-upload (see below)

### Re-upload a new version
1. Go to the repo on GitHub
2. Click `index.html` → click the ✏️ pencil (Edit) icon
3. Paste the updated file content
4. Scroll down → click **Commit changes**
5. GitHub Pages auto-deploys within ~60 seconds

### Or via terminal
```bash
git clone https://github.com/certkraft/certkraft-presentation.git
cd certkraft-presentation
# replace index.html with your updated file
git add index.html
git commit -m "Update presentation"
git push origin main
```
